# Due Care
A personal website by Nang Kim Siing, covering humanitarian compliance, assurance, risk, learning and accountability.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, due-care).
2. Upload the contents of this folder directly to the repository root, including index.html, all six other HTML pages, due-care.css, due-care.js, and .nojekyll. Do not upload the containing folder itself.
3. Commit the files.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose main and / (root), then Save.
7. Wait for deployment; GitHub will display your published website link in Settings > Pages.

## Local preview
Open index.html in a modern browser. Keep the HTML, CSS and JavaScript files together.

## Editing
- Use the English / မြန်မာ buttons in the header to change language. The choice is remembered in this browser.
- due-care-i18n.js: Burmese translations for pages, articles, form messages and CSV templates. Keep translation keys in sync when editing English text. JavaScript is required for language switching; the default HTML is English.
- index.html: homepage
- due-care-about.html: biography and embedded photo
- due-care-insights.html: articles
- due-care-resources.html: downloadable CSV templates
- due-care-projects.html: project stages and placeholders
- due-care-training.html: planned training
- due-care-contact.html: message preview
- due-care.css: shared styling
- due-care.js: shared interactions, article text and resource templates

The photo, logo and favicon are embedded. No installation or build is required.

## Current limitations
The contact form previews messages locally; it does not send email or store submissions. Project details and training dates are placeholders or forthcoming information.
